# TrustFabric — Advanced ML CAT II

**19MAM56 Advanced Machine Learning Lab · III M.Sc. AI & ML · V Semester**
Coimbatore Institute of Technology

TrustFabric compares a transparent TF-IDF/logistic-regression baseline with a tuned word-and-character TF-IDF classifier for three-class claim-credibility triage. It also preserves the existing FastAPI evidence-verification interface and the separate optional privacy/media backend.

> **Interpretation boundary:** the LIAR-trained classifier predicts dataset labels from language patterns. It is not evidence that a claim is true or false. The evidence-verification endpoint is a separate retrieval/NLI workflow and can also be incomplete or wrong.

## Status and deliverables

- Training, evaluation, figures, model artifacts, and the IEEE-style report are reproducibly generated by the commands below.
- `outputs/metrics/benchmark.json` is the machine-readable experiment record. The report is `report/TrustFabric_CATII_Report.pdf`.
- The AWS deployment and public GitHub publication are not reported as complete until the AWS service is healthy and real remote URLs have been verified. Never infer cloud deployment from a Docker build.

## Dataset and provenance

The experiment uses William Yang Wang's **LIAR** benchmark, downloaded from the dataset authors' official archive: [liar_dataset.zip](https://sites.cs.ucsb.edu/~william/data/liar_dataset.zip). The archive contains 10,240 training, 1,284 validation, and 1,267 test statements with six original labels. The project's preprocessing aggregates those labels:

| LIAR labels | Project target |
|---|---|
| `pants-fire`, `false` | `false` |
| `barely-true`, `half-true` | `mixed` |
| `mostly-true`, `true` | `true` |

The source distribution is **research use only**. Its README says that original sources retain copyright; it does not grant a general redistribution license. The dataset is therefore excluded from Git and the release ZIP. The training script downloads the official archive when needed and stores it locally under `data/raw/`.

Preprocessing preserves official source splits, removes blank statements and unknown labels, normalizes Unicode (NFKC), strips control characters, normalizes whitespace, and removes duplicate statement text before partitioning. The three-class mapping loses nuance, and LIAR consists of short, US political claims with human-assigned labels; it is not a general or current factuality benchmark. For a user CSV without a `split` column, the pipeline creates a stratified 70/10/20 train/validation/test split with seed 42. Vectorizers are fitted inside scikit-learn pipelines and cross-validation folds, preventing vocabulary leakage.

## Setup

Use Python 3.13.7 for the pinned environment. From the project root in PowerShell:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

The checked-in model and generated evaluation artifacts are included; the raw dataset is not. To download the data, retrain, and regenerate artifacts:

```powershell
python -m trustfabric.train
```

The default run performs a three-fold `GridSearchCV` search optimizing macro-F1 across six word n-gram/regularization combinations. Search folds use only the training partition. Validation metrics are recorded separately. After selection, each final model is refit on train plus validation and evaluated once on the unchanged held-out test partition. `--max-rows 1500 --skip-grid-search` is a development smoke run and must not be presented as the final tuned experiment.

For a compatible CSV with `statement` and `label` columns:

```powershell
python -m trustfabric.train --csv data/raw/my_claims.csv
python -m trustfabric.train --csv data/raw/my_claims.csv --text-column claim --label-column verdict
```

### Models and tracked experiment results

- **Baseline:** word unigram TF-IDF and class-weighted logistic regression.
- **Improved model:** word/character TF-IDF feature union and class-weighted logistic regression, selected by training-only stratified 3-fold CV.
- **Metrics:** accuracy, macro precision/recall/F1, per-class scores, one-vs-rest macro ROC-AUC, macro average precision (PR-AUC), and log loss.
- **Artifacts:** `outputs/models/`, `outputs/metrics/`, and `outputs/figures/`. `benchmark.json` records the split protocol, counts, seeds, package versions, selected parameters, CV history, timings, and limitations. `error_analysis.csv` contains both models' predictions on the same test examples and SHA-256 statement fingerprints, not redistributed claim text.
- **Representation analysis:** the sparse word/character TF-IDF space is inspected with class-specific linear coefficients rather than dense PCA, which would discard sparse lexical structure and reduce interpretability.

Published work is cited for context, not represented as a score reproduced under a compatible split or label scheme. The project does not claim state-of-the-art performance.

## Local application

Start the FastAPI application:

```powershell
uvicorn app.api:app --host 127.0.0.1 --port 8000
```

Open `http://127.0.0.1:8000/` for the interactive UI. API routes:

- `GET /health` and `GET /api/v1/health`
- `GET /api/metrics`
- `POST /api/predict` — dataset-trained model output; validates text and explicitly warns that output is not a fact check.
- `POST /api/v1/verify` — distinct evidence retrieval and NLI assessment. Input is JSON such as `{"text":"A factual statement to assess."}`; malformed, blank, or overlong input is rejected. Search candidates and NLI judgments are not guarantees of truth.
- `GET /docs` — interactive OpenAPI documentation.

The extension's optional privacy/media service is separate and remains on port 8765. Install its dependencies with `python -m pip install -r extension_backend/requirements.txt`, then start it from the project root with:

```powershell
uvicorn extension_backend.app.main:app --host 127.0.0.1 --port 8765
```

The extension backend accepts an optional API key and bounds text/upload sizes; use its `.env.example` as a configuration guide and never commit a real `.env` file.

## Docker

Build after the trained model exists:

```powershell
docker build -t trustfabric-cat2 .
docker run --rm -p 8000:8000 trustfabric-cat2
docker inspect --format='{{.State.Health.Status}}' (docker ps -q --filter ancestor=trustfabric-cat2)
```

The image uses Python 3.13.7, pinned direct dependencies, a non-root user, and a health check that requires the model-loaded `/health` response. It includes the trained model and benchmark JSON but excludes datasets, caches, tests, and optional extension services. Validate `/health` and real inference through the running container before deployment.
